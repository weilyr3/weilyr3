Tenho interesse em construir ambientes utilizando uma arquitetura baseada em containers:

```text
                    ┌───────────────────┐
                    │      Internet     │
                    └─────────┬─────────┘
                              │
                              ▼
                    ┌───────────────────┐
                    │ Reverse Proxy     │
                    │   Nginx / Caddy   │
                    └─────────┬─────────┘
                              │
             ┌────────────────┼────────────────┐
             │                │                │
             ▼                ▼                ▼
       ┌───────────┐    ┌───────────┐    ┌───────────┐
       │ Laravel   │    │   Worker  │    │ Scheduler │
       │    App    │    │   Queue   │    │           │
       └─────┬─────┘    └─────┬─────┘    └───────────┘
             │                │
             └────────┬───────┘
                      ▼
              ┌───────────────┐
              │     Redis     │
```
